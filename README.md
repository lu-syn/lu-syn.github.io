## Featured Projects

**DIG Procurement System**
A full-stack platform covering pricing, client proposals, ordering and delivery tracking. Outside warehouses record deliveries from their phones, and each one sees only its own work, enforced in the database with row-level security. Built with AI-assisted development; 377 database checks, each proven by mutation testing to fail when its rule breaks.
`Next.js` `TypeScript` `PostgreSQL` `Supabase` `Row-Level Security` `Vercel`

**SpeedReading App** · [GitHub](https://github.com/birongliu/speedreading)
A progressive web app that trains users to read faster without losing comprehension. Upload a PDF, set a target WPM, and an AI-generated quiz checks retention after each session.
`Next.js` `Node.js` `Supabase` `Groq API` `TypeScript` `Tailwind CSS` `PWA`

**Beyond Barriers** · [GitHub](https://github.com/annabelenko/CISC4900)
A 2D educational platformer simulating campus navigation with peripheral vision loss, with AI quiz questions generated from research PDFs (RAG), ElevenLabs narration and a real-time anxiety meter. Presented at Brooklyn College CIS Day 2026.
`Phaser 3` `JavaScript` `Python` `FastAPI` `Google Gemini` `LangChain`

**BC CS Club Website**
Open-source Brooklyn College CS Club site. Built a live room-status feature for the e-board and a resources page used by 900+ CS students to find tutoring and study materials.
`TypeScript` `Tailwind CSS`
